# MiniSocial

## 📌 Project Description

MiniSocial is a social media web application built using Django.

Users can:
- Register and Login
- Create Posts
- Upload Images
- Like Posts
- Comment on Posts
- Edit their Profile
- Upload Profile Pictures

## 🛠 Technologies Used

- Python
- Django
- HTML
- CSS
- SQLite

## 🚀 Features

- User Authentication
- Create and View Posts
- Image Upload
- Like System
- Comment System
- Profile Management
- Responsive User Interface
